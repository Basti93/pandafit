# Gym Coach Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A separate strength area with its own coach that plans muscle-building workouts from the rider's Hevy history and, after a confirmed preview, writes them to Hevy as one rolling routine, plus an overview per person with shared health.

**Architecture:** New modules under `src/coach/gym/` run in the coach process beside the unchanged bike `Coach`, with their own state file. Pure functions decide availability, progression and limits; the AI only proposes and those functions check it. The Hevy client gains routine writes, and the UI gets one new page.

**Tech Stack:** TypeScript, zod, React, vitest, `askClaude` through `Deps.ask`, Hevy REST API.

**Spec:** `docs/archive/specs/2026-11-02-gym-coach-design.md`. First version: muscle growth only, with `goal` stored so that other goals can follow.

## Global Constraints

- Everything is optional per profile: with no Hevy key there is no strength button, no call, no error.
- No Hevy write, AI call or pull while a ride is open. Nothing here touches `src/service/**`.
- The only Hevy writes are: create a folder titled `Bike Coach`, create a routine in it, update that routine. Nothing else, and never without the rider's confirmation message.
- The bike `Coach` never creates strength workouts. It gains only `addComplaintFromText`.
- The repository is public: tests use invented data, and no personal values in commits or docs.
- All visible text is German, without guilt, pressure, streaks or comparisons.
- Limits, fixed in `src/coach/gym/limits.ts` and documented in `docs/gym-foundations.md`: `RECENT_DAYS = 120`, `LONG_BREAK_DAYS = 28`, `MIN_COMPARABLE = 2` sessions of an exercise within the last 56 days, `STEP_BACK = 0.9`, `MAX_STEP_PCT = 5` or at least 2.5 kg, `REP_MIN = 6`, `REP_MAX = 12`, `MAX_EXERCISES = 10`, `MAX_SETS = 30`, `MAX_FAILURE_SETS = 4`, `MAX_WIDOWMAKERS = 1`. Failure and widowmakers are forbidden on equipment `barbell`.

## Review Focus

- Hevy changes a template id or the rider's custom exercise is gone: the workout is rejected and rebuilt, nothing half-written reaches Hevy (Task 5).
- The coach's routine or folder was deleted by the rider in Hevy: a PUT 404 creates a new one and does not fail (Task 3).
- Stored workouts from the current format lack set details: they are refetched once without losing data meanwhile, and the bike coach keeps working during the refetch (Task 1).
- Confirming twice quickly, or confirming a stale preview: only one write, and the routine matches what was shown (Task 7).
- Bodyweight exercises with no weight: no weight is invented and reps still progress (Task 2).
